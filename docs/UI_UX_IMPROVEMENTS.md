# Plan de Mejoras UI/UX - NeoSynth

Este documento detalla las mejoras visuales y de experiencia de usuario acordadas para elevar la calidad de la aplicación NeoSynth, manteniendo su estética **Sophisticated Noir**.

## 1. Lyrics Editor (Sincronización Pro)
- [x] **Monitor de Tiempo de Comparación:** Mostrar el tiempo actual del reproductor junto a los controles de reproducción para comparar con los tiempos asignados a las líneas.
- [x] **Focal Point (Modo Enfoque):** Resaltar la línea activa con un cambio sutil de color y escala, aplicando desaturación a las líneas inactivas.
- [x] **Ajuste Fino (Fine-Tuning):** Controles de `+/- 100ms` en la línea seleccionada para ajustes de precisión quirúrgica.
- [x] **Barra Predictiva:** Indicador visual dentro de la tarjeta de la letra que muestra el progreso hacia la siguiente frase.
- [x] **Feedback Háptico:** Vibraciones cortas al capturar tiempos con el cronómetro.

## 2. Discover (Exploración Fluida)
- [x] **Efecto de Profundidad:** Sombras dinámicas en portadas para generar capas visuales sobre el fondo `DeepNoir`.
- [x] **Cabeceras Adaptativas:** Gradientes sutiles en chips y tarjetas (Género/Década) para una estética Premium.
- [x] **Skeletons Premium:** Animaciones de carga con barrido de luz suavizado y formas coherentes con el nuevo diseño.

## 3. Downloads (Gestión Visual)
- [ ] **Indicadores Dinámicos:** Animaciones de estado (descargando, completado, error) más visuales.
- [ ] **Visualización de Almacenamiento:** Gráfico de uso de disco por descargas.
- [ ] **Gestos Intuitivos:** Implementación de "Swipe to Delete" con feedback inmediato.

## 4. Estética General
- [x] **Sophisticated Noir:** Implementación de gradientes radiales muy oscuros para evitar la planicidad del negro puro.
- [ ] **Transiciones Fluidas:** Optimización de animaciones entre pantallas.
